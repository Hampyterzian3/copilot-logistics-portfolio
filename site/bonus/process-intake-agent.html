Process Intake Agent

An AI agent that interviews a business user about a manual process, scores it against a transparent rubric and recommends the right automation route, so ideas reach the automation team as a clear, comparable intake instead of an email.

01Problem

  • Automation requests arrive as vague emails; consultants spend the first meeting collecting basics.
  • Teams over-reach for pro-code, or automate steps that should be removed.
  • Risk is spotted late: credit, payments and personal data need review before design.

02What it does

  • Asks 8 short questions, one at a time, and skips what is already known.
  • Scores six criteria 0 to 3 (volume, rules, data, stability, systems, time).
  • Estimates hours saved with the formula shown, as a range.
  • Produces a structured intake summary card ready for the backlog.

03Four routes, one recommendation

Not worth automatingLow score or under 40 hours a year. Simplify or remove the step.
Out of the boxPersonal productivity on documents and email: Microsoft 365 Copilot.
Low-codeTeam processes on M365 and standard connectors: Copilot Studio, Power Automate.
Pro-codeHigh volume, core system APIs or complex logic: engineering backlog.

04How it is built

1InstructionsRole, 8-step flow, scope, tone and refusal rules.
2KnowledgeOne playbook as the only source; web search off.
3TopicsDeterministic PII guard, escalation and out-of-scope.
4CardAdaptive Card summary with log or edit actions.
5FlowOptional Power Automate tool logs the intake to Excel.

05Guardrails

  • Grounded in a single knowledge source with citations; says when the playbook does not cover a question.
  • Never asks for or repeats personal data; a topic stops the conversation if it is pasted.
  • High-risk processes always routed to human review; the agent recommends, a consultant confirms.
  • No memory; the log stores process descriptions only.

06Testing and reuse

  • Test set of 8 scenarios: happy path, honest "not worth it", high risk, pasted IBAN, off-topic, hand-off, unknown answer.
  • Run in Copilot Studio Preview and Evaluate before recording.
  • Reusable: swap the playbook to run intake for HR, procurement or operations.
