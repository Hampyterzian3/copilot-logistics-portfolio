        How this maps to Microsoft 365 in production.
        • Sample RFQ folder: a document library in SharePoint, one folder per RFQ with lanes.csv and requirements.md.
        • Run check: a Power Automate flow triggered when a new RFQ folder is created calls the Python checker (Azure Function behind a custom connector), stores lanes and gaps in Dataverse and posts an adaptive card to the Tender Desk channel in Teams.
        • Lanes, gaps and outline tabs: the checker output. In this page the same nine rules run in JavaScript and are tested for identical results against the Python version.
        • Draft letter and solution outline: Microsoft 365 Copilot in Word and PowerPoint, prompted with the generated summary file.
