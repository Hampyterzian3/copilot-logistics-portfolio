Contoso Logistics runs the inbound network for an automotive OEM plant in central Germany: 60 suppliers across Europe. For each supplier the planner can choose direct full-load, a regional milk-run or cross-dock consolidation through one of three hubs. Move the sliders, pick a design on the map, and ask the agent why it recommends the mix it does. Every number below is computed live by the network engine on synthetic data.

Network Scenario Agent

Simulation of the Copilot Studio agent: fixed intents and rules in this page stand in for the generative answers. In production it calls the scenario connector as a tool.

How this maps to Microsoft in production. Sliders and results table: Power Apps canvas app (or the Copilot Studio chat itself). Network engine: Python package written with GitHub Copilot, hosted in an Azure Function (POST /scenarios). Tool call: Power Platform custom connector from the OpenAPI file, added to the agent as an action. Chat panel: Copilot Studio agent "Network Scenario Agent" with topics Run a scenario, Compare designs, What if fuel price changes and Explain recommendation. Scenario log: Dataverse tables via Power Automate. Map: Power BI map visual on the logged flows. Here, the engine is ported to JavaScript and checked against the Python baseline.
