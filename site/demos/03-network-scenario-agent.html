Network Scenario Agent

Contoso Logistics runs the inbound network for an automotive OEM plant in central Germany: 60 suppliers across Europe. For each supplier the planner can choose direct full-load, a regional milk-run or cross-dock consolidation through one of three hubs. Move the sliders and pick a design on the map to see why the engine recommends the mix it does. Every number below is computed live by the network engine on synthetic data.

How this maps to Microsoft in production. Sliders and results table: Power Apps canvas app. Network engine: Python package written with GitHub Copilot, hosted in an Azure Function (POST /scenarios). Scenario log: Dataverse tables via Power Automate. Map: Power BI map visual on the logged flows. Here, the engine is ported to JavaScript and checked against the Python baseline.
