    In production: the tokens files live in a GitHub repo and GitHub Copilot helped write the build script and tests; a GitHub Action runs node src/build_themes.mjs on every change.
    tokens.css / tailwind.theme.js style web apps (DPark is React + Tailwind on Netlify).
    powerapps-theme.json feeds the modern theme of Power Apps canvas apps.
    office-theme1.xml goes into the organisation's Word and PowerPoint templates in a SharePoint organisation assets library, which Microsoft 365 Copilot uses when it drafts a document or deck.
    The Copilot Studio agent icon and colour are set from the same palette. The assistant on this page is a deterministic simulation of a Copilot Studio agent.
