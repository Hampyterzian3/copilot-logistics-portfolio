Invoice intake, simulated

This page replays the logic of the Invoice Intake Agent I built in Python on 12 of its synthetic invoices. The validation checks are a line-by-line port of its validate.py and run in your browser. Extracted fields come from the app's ground-truth file; the confidence scores are illustrative, because the built app's rule-based reader does not produce them. The agent panel simulates the Copilot Studio exception assistant from the Power Platform design.

Exception assistant simulation
How this maps to Microsoft components in production. Inbox and upload: SharePoint document library or Outlook shared mailbox trigger in Power Automate. Extraction table and confidence: AI Builder invoice processing (prebuilt) or a custom document processing model. Validation checks: Power Automate conditions with lookups to Dataverse vendor and purchase order tables. Register, exception queue and audit trail: Dataverse tables surfaced in a Power Apps model-driven app, with a Teams adaptive card for the reviewer. Exception assistant: Copilot Studio agent with three topics reading and updating Dataverse. The built Python app does the same with pdfplumber or Claude for extraction, SQLite for the register and audit log, and Streamlit for the UI.
