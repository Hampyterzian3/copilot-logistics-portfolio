# Tender Desk: knowledge sources

| Source | Type in Copilot Studio | What the agent uses it for |
|---|---|---|
| SharePoint site `Tender Desk`, library `RFQ Library` (one folder per RFQ: `lanes.csv`, `requirements.md`, `rfq-summary.md`) | SharePoint knowledge | Scope questions, quoting the customer's own requirements, citing files |
| Dataverse tables `Tender`, `RFQ Lane`, `RFQ Gap`, `Clarification Question` (see `../dataverse/schema.md`) | Dataverse knowledge | Gap counts, lane flags, suggested mode per lane, question status |
| SharePoint page `Tender rules R01 to R09` (rule ids, thresholds, why each matters) | SharePoint knowledge | "Explain a gap" answers stay consistent with the checker |
| SharePoint library `Solution templates` (Word clarification letter template, PowerPoint solution outline template) | SharePoint knowledge | Copilot in Word and PowerPoint drafts start from the approved templates |

Not used: public web search, other customers' folders (library permissions are broken per RFQ folder so the agent only sees what the signed-in user can see).

## Synthetic data in this repo
- `data/northwind-europe-2027/`: 40 lanes, 25 seeded gaps (fictional shipper Northwind Components).
- `data/northwind-spares-2027/`: 18 lanes, 3 gaps.
- Generated by `src/generate_data.py` (seeded, reproducible).
