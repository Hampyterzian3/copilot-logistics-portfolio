## Honest labels
- Projects 01 to 05 use a fictional company (Contoso Logistics) and synthetic data generated by the scripts in each folder.
- The web demos simulate the Copilot Studio agents with deterministic logic in the browser. Each folder holds the agent instructions, topic YAML, flow specs and Dataverse schema to build the real thing in a tenant.
- Projects 07 and 08 were built outside the Power Platform; their folders describe the Microsoft-stack equivalent as a design.
- Project 09, Baynook, is a live product built for mttn (Mitten Digital Solutions LLC). Its code lives in a private repository and its public demo runs on a fictional office with demo data reset nightly.

## Layout
```
projects/0N-<slug>/   code, tests, Copilot Studio, Power Automate, Dataverse artefacts
site/                 static site deployed to Netlify (no build step)
  data/projects/      one JSON per project (named after its media/NN folder), feeds the panels and camera rolls
  demos/              interactive demo pages
tools/build-site.mjs  regenerates site/index.html from the JSON and the page template
tools/page.template.html  everything outside the project panels (head, intro, method, contact, scripts)
```

## Edit the home page
- Project content: edit `site/data/projects/NN.json`. `order` sets the position on the page; sections are numbered p01, p02, ... in that order.
- Anything else (intro, method, contact, meta tags): edit `tools/page.template.html`. Bump the `?v=` cache versions there when CSS or JS changes.
- Then run `node tools/build-site.mjs`. `node tools/build-site.mjs --check` reports whether `site/index.html` is up to date without writing it.
- Do not edit `site/index.html` by hand: the next build overwrites it.

## Run locally
```bash
node tools/build-site.mjs
python -m http.server 8080 --directory site
```

## Tests
Each project is tested on its own (module names overlap between projects):
```bash
for p in projects/0[1-5]*; do (cd "$p" && python -m pytest -q); done
(cd projects/06-brand-theme-systems && node --test)
```
Current result: 137 pytest tests and 7 node tests pass.

## Deploy
Netlify, connected to this repository. `netlify.toml` publishes `site/` with security headers.
